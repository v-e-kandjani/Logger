Yöntem 2: Manuel Kurulum & Systemd Servisi Yapılandırması

Air-gapped (çevrimdışı) veya özel dağıtımlar için manuel kurulum adımları:

Adım A: Dizinleri ve İkili Dosyayı Hazırlama
sudo mkdir -p /opt/logger-agent/bin /etc/logger-agent /var/log/logger-agent
sudo cp logger-agent /opt/logger-agent/bin/logger-agent
sudo chmod +x /opt/logger-agent/bin/logger-agent
Adım B: Yapılandırma Dosyası (/etc/logger-agent/config.json)
sudo tee /etc/logger-agent/config.json > /dev/null << 'EOF'
{
  "server_url": "http://localhost:8080",
  "enrollment_token": "<TOKEN>",
  "insecure_tls": false,
  "log_level": "info",
  "data_dir": "/opt/logger-agent/data",
  "heartbeat_interval_sec": 30,
  "identity_file": "/etc/logger-agent/identity.json"
}
EOF
sudo chmod 600 /etc/logger-agent/config.json
Adım C: Systemd Servisini Oluşturma ve Başlatma
sudo tee /etc/systemd/system/logger-agent.service > /dev/null << 'EOF'
[Unit]
Description=Valtrivo LogSeal Native Endpoint Security Agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
ExecStart=/opt/logger-agent/bin/logger-agent -config /etc/logger-agent/config.json
Restart=always
RestartSec=5s
LimitNOFILE=65536
StandardOutput=append:/var/log/logger-agent/agent.log
StandardError=append:/var/log/logger-agent/agent-error.log

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now logger-agent
sudo systemctl status logger-agent
